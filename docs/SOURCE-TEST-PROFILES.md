# 测试配置

`pnpm test:public` 运行两仓共用的本地测试配置，覆盖主应用启动与停止、管理员认证、编辑与审核、运营规则、原生能力目录和 GitHub 适配器。测试启动时列出所选文件及当前仓库中未选的文件。这个配置在公开仓也是 `pnpm test` 的默认入口。

私有生产仓继续通过 `pnpm test` 运行现有全量主应用测试。额外用例中，有些依赖运营账号布局、内部数据迁移样本、原生媒体资产或平台工具。公开仓包含可分发的测试源码。若单独运行配置之外的用例，请先独立准备该用例需要的合成数据或已获准使用的资源。

两仓的 `pnpm smoke` 使用同一份隔离演示数据，启动临时本机实例并检查公开页面、登录、后台和 GEO 入口。退出后由脚本清理临时文件。

# AI Agent guide

Run `node scripts/agent.mjs guide`, or call `pengmanager_agent_guide` from a configured MCP client, to read the fixed guides for your checkout. Tool discovery and capability registration are read-only.

Use the local operator console for creating or approving work. HTTP Agent credentials have a narrower scope than administrators. The server checks the active actor, permitted operation and supplied approval before accepting a write. Inspect the corresponding implementation before building a client integration.

Keep the exact user brief, account, target, data authorization and budget with the operation. Read an existing job or receipt when a request outcome is unknown. A preview, queued job, local file, or adapter capability is not evidence of external publication or paid generation.

The local demo never dispatches provider work. The optional native video runtime needs its own validated checkout components, owner data directory and provider configuration. See [video integration](CODEX-VIDEO-QUICKSTART.md).
